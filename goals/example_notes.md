請直接開始，做到完，不要停下來問我。需要選擇的地方，一切皆採建議值。這份文件就是全部的指示。

【目標】
把 notes/ 裡這一週讀書會的三份筆記（拍照轉成的文字檔），整理成一份 summary.md，放在 notes/out。

【品質標準與品味】
兩層都到，才算合格：
- 規定：【關卡】的清單每一條都打勾。
- 品味：8 分以上，滿分 10。五條，每條 0、1 或 2 分，每個分數都要指出是哪一段：
1. 沒來的人讀完，知道這一週讀到哪裡、大家爭的是什麼。
2. 三個人的意見都在，不是只寫說最多話的那一個。
3. 一段只講一件事。
4. 用我們自己的說法，不換成教科書的詞。
5. 一頁看得完。

【自我檢查】
每一輪做完，用沒來的那個人的眼睛問自己三題，各答一句，寫進紀錄：
- 我讀完，知道下一次要讀到哪裡嗎？
- 有沒有哪一句是我自己補的，筆記裡找不到？
- 誰的意見被我寫得比較少？
答不出來的，就是下一輪要補的。

【工具】
數字數、核對小標題，每一輪都要重做：先寫成一支小程式放在 notes/out/tools/，每一輪都執行它，不要目測。哪一段寫得好不好，你自己判斷，不要做成程式。

【規則】
- 不要改 notes/ 裡的原始筆記。
- 不要補筆記裡沒有的內容；看不清楚的字，寫「（看不清楚）」，不要猜。
- 不要為了一頁看得完，刪掉某一個人的意見。
- 只寫 notes/out 裡的檔案。

【關卡】
這件事沒有程式可以跑。每做完一輪，你自己照這張清單一條一條檢查，寫進 notes/out/check.md，每一條寫 [v] 或 [ ]，加一句證據：
[ ] 三份筆記的每一個小標題，summary.md 裡都找得到
[ ] 每一段後面都標了出處（哪一份筆記）
[ ] 沒有筆記裡找不到的人名、書名、頁碼
[ ] 最後一行寫了下一次要讀的範圍
[ ] 全文 800 字以內

【每一輪的紀錄】
每一輪在 notes/out/log.md 最後加一段：第幾輪、清單幾條打勾、品味幾分（五條各幾分）、最弱的一條和證據、自我檢查三題的回答、改了什麼、下一輪要改什麼。

【停止】
- 清單第一次全部打勾之後，至少再做一輪：只改品味最弱的那一條，清單要保持全勾。
- 做完這一輪，清單全勾，而且品味 8 分以上：停。
- 最多 3 輪。跑滿還沒到也要停，列出還沒過的項目，各寫一句卡在哪裡。
